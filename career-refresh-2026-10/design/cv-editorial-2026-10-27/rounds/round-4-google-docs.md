# Google Docs 제작용 CV 디자인 명세

현재 시안: `round-4`. 실제 HTML A4 레이아웃과 이 문서는 같은 `editorial-design.json` / `editorial-content.json`에서 생성합니다. 시각 자료는 `http://localhost:3100/studio/cv-editorial-2026-10-27/index.html`에서 확인합니다.

붙여넣을 영어 본문은 같은 데이터로 생성한 `editorial-copy.md`에 있습니다. 미리보기의 Copy CV text 버튼으로도 복사할 수 있습니다.

## 디자인 방향

이름은 크게, 경력 근거는 차분하게 읽히도록 구성합니다. 머리말의 두 정렬선, 짧은 초록 선, 옅은 기술 영역과 글자 위계가 디자인 요소입니다. 사진, 숙련도 점수, 장식 타임라인을 추가해 공간을 채우지 않습니다.

## 1. 실제 지면과 여백

- A4 세로, 210 × 297mm, 흰색.
- 좌우 18mm, 위 15mm, 아래 16mm.
- 본문 폭 174mm. 왼쪽 정렬.
- Google Docs에서 페이지 모드, 인쇄 레이아웃과 눈금자를 켭니다.

## 2. 서체와 크기

| 요소 | 서체 | 크기 | 굵기 | 색 |
| --- | --- | --- | --- | --- |
| 이름 | Manrope | 34pt | Bold 700 | `#1C2922` |
| 직무 | Inter | 11pt | Medium 500, 없으면 Regular | `#1B4D3A` |
| 회사 | Inter | 12.5pt | Bold 700 | `#1C2922` |
| 본문 | Inter | 10.5pt | Regular 400 | `#1C2922` |
| 날짜·위치·기관 | Inter | 9.5pt | Regular 400 | `#59655E` |
| 섹션 제목 | Inter | 10pt | Bold 700 | `#1B4D3A` |

Docs의 글꼴 더보기에서 Manrope와 Inter 제공 여부를 확인합니다. 사용할 수 없으면 이름은 Manrope 대신 Arial Bold, 본문은 Inter 대신 Arial로 통일하고 줄바꿈을 다시 확인합니다. HTML의 미세한 자간은 Docs에서 똑같이 지정할 수 없으므로 공백 문자로 흉내 내지 않습니다.

## 3. 머리말

왼쪽에 이름, 직무, Leuven 위치를 세 줄로 둡니다. 오른쪽에 이메일, 웹 주소, LinkedIn/GitHub 링크를 세 줄로 정렬합니다.

Docs에서는 머리말에만 테두리 없는 2열 표를 사용할 수 있습니다. 표는 본문 폭에 맞추고 오른쪽 열을 약 43mm로 둡니다. 셀 여백은 0~1mm, 왼쪽 셀은 왼쪽 정렬, 오른쪽은 오른쪽 정렬입니다. 본문 경력은 표로 만들지 않습니다.

머리말 아래에는 0.5pt `#D5DED7` 선을 한 번 사용합니다. HTML의 짧은 34mm 초록 강조선은 Docs에서는 선택 사항입니다. 선을 여러 개 겹치기보다 하나의 깔끔한 구분선을 우선합니다.

별도 태그나 요약 문단을 더 넣지 않습니다. C++ 직무와 최근 경력의 첫 문장이 핵심 분야를 설명합니다. 머리말의 아래 여백은 4mm입니다.

## 4. 경력과 날짜

회사명은 12.5pt Bold, 이어지는 직함은 10.5pt Regular로 둡니다. 날짜는 9.5pt로 오른쪽 탭 정지점에 맞춥니다. 왼쪽 본문 기준선에서 174mm 위치의 오른쪽 탭을 사용하고, 공백 여러 개로 정렬하지 않습니다.

경력 사이의 간격은 7pt, 섹션 앞은 9pt입니다. 본문은 10.5pt / HTML 기준 14pt 줄 간격입니다. Docs의 배수 간격은 글꼴 메트릭의 영향을 받으므로 1.15~1.2에서 시작해 화면과 인쇄 결과를 보며 조정합니다. 줄 간격 입력란에 `14`를 배수로 넣지 않습니다.

불릿은 실제 목록으로 만들고 글 시작을 약 3.8mm 들여씁니다. 두 번째 줄은 첫 단어에 맞춥니다. 회사·팀/위치 행은 다음 단락과 함께 유지하고, 각 불릿은 줄을 함께 유지합니다.

## 5. 기술 영역

아래 내용을 실제 텍스트로 유지합니다. 라벨만 Bold로 둡니다.

```text
Languages: C++, C, Python; TypeScript, JavaScript
Systems: Error recovery, device communication, WebSocket, REST, ROS 1/2
Tools & UI: Git, Docker, Linux, Qt/QML, React; Figma / basic UI design
```

Docs에서는 기술 영역 전체를 한 개의 셀이나 단락 음영으로 묶어 `#F1F5F2` 배경을 적용할 수 있습니다. 테두리는 0.5pt의 옅은 회색, 안쪽 여백은 약 3mm입니다. 아이콘이 기술 이름을 대체하지 않게 합니다. Figma는 기본적인 UI 디자인 경험이라는 범위를 유지합니다.

## 6. 프로젝트와 학력

프로젝트명과 공개 저장소 링크를 연결하고, 본인 기여와 팀 수상 범위를 함께 적습니다. BCX 수상은 digital.auto & mobility challenge의 1위입니다. C++ containers는 42 프로젝트로 표시하며 vector, stack, AVL 기반 map과 iterator라는 실제 코드 범위로 설명합니다. 새 테스트를 통과했다고 주장하지 않습니다. Ariadne는 CV에서 제외합니다.

학력은 학위 취득과 진행 중 상태를 구분합니다. Computer Engineering과 Business Administration은 같은 기관 아래 각각의 취득 연도와 함께 묶을 수 있습니다. 42의 수료 연도는 만들어 넣지 않습니다.

## 7. 마무리

본문을 먼저 완성한 뒤 이름, 회사, 섹션 제목 스타일을 적용합니다. 넘치면 반복 표현과 선택 항목을 줄이고 간격을 조정합니다. 10.5pt 본문을 더 작게 줄여 한 페이지에 억지로 맞추지 않습니다.

HTML/PDF 검토 결과는 별도 리뷰 기록에 남깁니다. 실제 Google Docs 조판·내보내기·ATS 처리는 아직 검증한 것이 아닙니다. 링크와 복사된 텍스트 순서를 확인하고, 글꼴이 바뀌면 페이지 수를 다시 확인합니다.
