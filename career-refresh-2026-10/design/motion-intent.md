# Direction after the motion/design correction

26 October 2026. This supersedes the previous restraint-only direction where it conflicts with the owner's latest request.

## Purpose

The previous site was orderly but physically inert. The owner meant a much more dynamic interface: collectible-card tilt, foil and turning; a reactive homepage; an atmospheric green cinematic background. Responsive layout alone does not satisfy that request.

The new concept uses the green window photograph as light and atmosphere. A fixed dark-green environment supports a genuinely reactive personal card. Professional information and direct CV/contact actions remain easy to reach.

## Decisions

- Remove the separate K mark. Use a plain name/domain wordmark.
- Use one deliberate colour treatment; remove the light/dark selector.
- Build a layered card with bounded pointer tilt, moving reflection, depth and a real front/back transition. Preserve explicit keyboard/touch controls.
- Add photo/background response on the homepage, using CSS compositing and small pointer-driven CSS variables rather than a large animation framework.
- Keep text stable enough to read. Use motion pause and reduced-motion behaviour without hiding information.
- Redesign the CV's information hierarchy and page use as a detailed Google Docs specification only. The owner's later correction stops new CV PDF/DOCX/generator work.
- Remove Ariadne from the CV. On the site it can remain only as an honestly attributed AI-built/configured experiment.
- Describe Pickit through communication/interface system design and integration, bounded by known work.

## Advisory process

Two independent, simulated senior perspectives are examining the current renders before implementation: Apple-inspired motion/material/identity and Google-inspired information/accessibility/CV typography. They are advisory roles, not actual employees or endorsements. The main agent remains the sole writer.

The company coordination tool is scoped to the KLA Git family and does not register this separate personal repository. Company code, other agents' reservations and instructions are left untouched. This work uses at most two read-only advisors and one writer.

The brief CV-production continuation was canceled. No new CV PDF/DOCX or generator was produced by that continuation; font assets were downloaded before cancellation. Subsequent advice is text only.
