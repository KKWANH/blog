## Affected versions
4.0 and `kinetic-devel`. 

## Description
When using the C100, teaching the empty ROI box volume on a ROI Box that still contains a bit of points keeps the threshold to 0mm3 in the UI. It's not just a display issue, since detecting afterwards on that empty ROI does not lead to the "ROI box is empty" result. The scene on which I tested was clearly full of points in the ROI though:

<img alt="image" src="./specs/image.png" />

## How to reproduce
1. Open the snapshot `/share/intermodalics/pickit/snapshots/2_issues_and_debug/issues/10960/2025-11-17T11:00:56Z_define-empty-roi-box-c100-not-working.snapshot`
2. Click on Define empty ROI box -> Teach from scene
3. See that volume threshold remains 0 mm3
4. Click detect
5. See that there is no pop up saying "The ROI box is empty"
