Color Saves Life was a team project at Bosch ConnectedExperience in Berlin in February 2024. The prototype explored visual assistance for drivers using simulation, image processing and eye-tracking.

The team won **first place in the digital.auto & mobility challenge** at BCX 2024.

## My contribution

I built a plugin-based Python client, integrated eye-tracking with the simulation pipeline and presented the team's work.

The plugin structure gave each processing feature a separate place in the client. The team used ROS 2 and Gazebo for the prototype environment.

## Scope

This was a hackathon prototype. It was not validated for use in a vehicle on public roads. The repository includes the project structure, demonstration material and setup instructions.

[Explore the team project on GitHub](https://github.com/KKWANH/ColorSavesLife).
