# Project image sources

The Color Saves Life viewer uses actual images from the team's public project repository:

- `bcx-simulation.webp`: `assets/imgs/simulation_world.png`
- `bcx-driver-view.webp`: `assets/imgs/car_road_view.png`
- `bcx-architecture.webp`: `assets/imgs/architecture-prototype.png`

Source repository: https://github.com/KKWANH/ColorSavesLife

The MIT license is retained at `public/project-media/ColorSavesLife-LICENSE.txt`. Images were converted to WebP for display. They are attributed as team-project material; the site does not claim that Kwanho individually created the entire simulation or architecture.

The demo film is sourced from `assets/presentation/demo.mp4` in that repository:

- Original: 1920×1104, H.264, 30fps, 16.3 seconds, no audio stream.
- Web derivative: `bcx-team-demo.mp4`, 1600×920, H.264/yuv420p, fast-start, approximately 1.92MB. Metadata was removed.
- Poster: `bcx-demo-poster.webp`, from the six-second frame.

The clip is not assigned to a video element until the visitor requests playback. It has native controls, a visible text alternative and the original-recording link. Offscreen/hidden-page playback pauses. Reduced motion prevents ambient/spatial effects; it does not forbid a deliberately requested video.

Third-party design-reference screenshots are private research artifacts, not application assets.
