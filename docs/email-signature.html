Gmail signature

  1. Press Copy under the version you want (or select just that block and copy).
  2. Gmail → Settings → See all settings → General → Signature → Create new, paste, and save at the bottom.
  3. Set it as the default for new emails and replies (for the address you send from).

The images load from www.kwanho.dev, so push and wait for the deploy before pasting. To change the card later, publish a new -v2.png rather than overwriting: Gmail's image proxy keeps the old file.
