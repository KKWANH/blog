# Skill context

The profile combines owner-stated skills, professional work and clearly labelled project practice. It does not derive proficiency from repository language percentages.

The completed 27 October 2026 review covers all 74 public KKWANH repositories individually: 73 have inspected text sources and one is empty. The initial catalogue records 336 inspected documentation, manifest and source files, with 77 technology/reference topics. It is in `contents/about/repositories.generated.json`; curated project contexts remain in `lib/skill-projects.ts`.

The profile has 44 experience/practice entries. The optional repository-stack view also exposes technologies from templates, references and AI-directed projects without treating their presence as personal proficiency. The Repositories tab exposes every record, its context and inspected file links.

The definitions now live in `contents/about/skill-definitions.json`. Owner familiarity/visibility is separate in `skill-profile.json`; neither repository presence nor sync assigns a level. [The editor and sync workflow](skills-editor.md) documents the schema, access policy and review-pending state for later source changes.
